2. Edit and save as a new design

Choose a design above to start from.

Or: a brand-new design from files

For a circuit the flow has not seen. Required: a SKY130 SPICE netlist and its specs (config). Everything else is optional: without test benches the standard ones are generated; other files (schematics, notes) are only kept with the design. Nothing is invented: a value you leave out stays empty and the flow reports it as pending.
